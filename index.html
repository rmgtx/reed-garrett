Proof pillars

Three systems that had to survive the floor

Harness, high-stakes domain tooling, and a client delivery surface. Architecture and outcomes only — anonymized, no private screenshots.

01

Sessioned Vision Intake → Human Confirm → ERP Write

Aerospace MRO · agent harness

Built a UI-agnostic agent harness that extracts structured work-order fields from multi-page industrial intake documents via vision, then writes to a tenant ERP contract — only after a technician confirms.

Separated the harness brain from a mobile-first intake UI, with a session state machine, knowledge-base lookup, and stub/live adapters so the loop runs offline-first. Then prototyped a workbench to design, evaluate, and export reusable agent packages — shared runner and templates — so the product is the loop and the package, not a one-off chat.

02

Cited Alternate-Part Validation Over a Controlled Corpus

Aviation maintenance · high-stakes domain AI

Built alternate-part validation tooling over a large OEM technical-manual corpus with three-way cited verdicts — confirmed, contradicted, or undetermined — and auditable per-claim method trails.

Authored a normative interchangeability knowledge base (OEM tokens, regulatory codes, legend precedence) and used it as authority to correct a systemic misclassification in the part graph. Undetermined stayed a first-class verdict; semantics beat more LLM calls. Controlled manuals stayed offline; the system carries code and docs only.

03

Print-Faithful Spec Viewer + Document-Aware Agent

Commercial interiors · client delivery

Built a print-faithful multi-page document viewer with deterministic PDF export and an embedded document-aware sales agent — for a commercial interiors / building-services manufacturer.

Print fidelity was a product requirement, not a nice-to-have: page-hash cadence against source art, lead capture on the edge, and messaging constraints treated as requirements. Rebuilt mocks only — no client screenshots here.
