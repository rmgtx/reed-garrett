# Public boundary

This repo is a **curated, anonymized projection** of private delivery work. It is not a mirror of any private catalog, client repo, or internal Build Library.

## Never ship

- Client legal names, logos, screenshots, or internal codenames
- Private repository links (`rg-tx/*`, unlisted remotes, contract folders)
- Unverified metrics (pilot ROI, ERP write rates, verdict slice counts)
- OEM manuals, claim sheets, CMM extracts, or controlled corpus content
- PII, credentials, `.env` values, tenant schemas, or ERP contracts
- Contracts, stubs, toys, or internal scoring systems

## Naming cheat-sheet (resume-safe)

| Keep private | Public framing |
|--------------|----------------|
| ICON / Apex / MachAI MRO | aviation MRO operator / aerospace MRO automation |
| Integrated Interiors | commercial interiors / building-services manufacturer |
| Beyond Painters | residential painting contractor |
| Axguard / Off the Grid | home battery backup / energy-resilience company |
| Mend InfoSec | mid-market enterprise InfoSec team |
| GoMachai / MACH.AI | agentic AI for industrial ops (omit brand unless cleared) |
| Kingside | omit unless cleared |

Default: **fully anonymized**. Name a client only after explicit clearance.

## Qualitative outcomes only

Prefer outcomes like “human confirm before ERP write,” “undetermined is a first-class verdict,” or “print fidelity as a product requirement.” Do not invent numbers. Do not publish Jester slice counts or pilot success rates without confirmation.

## Allowed public proof

- This site (GitHub Pages)
- Public open-source kits (e.g. [claude-html-kit](https://github.com/rmgtx/claude-html-kit), [PageEX](https://github.com/rmgtx/PageEX))
- Abstract architecture diagrams (no client UI, no real documents)
- Sanitized case-study copy rewritten from resume clusters

## Review checklist before any new public page

- [ ] Client names anonymized per cheat-sheet
- [ ] No private repo URLs
- [ ] No screenshots of client systems
- [ ] No metrics without explicit confirmation
- [ ] Diagrams are abstract / rebuilt mocks only
- [ ] Contact info is intentionally public
